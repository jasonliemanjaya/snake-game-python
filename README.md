   # Snake Game (Python Turtle)

   A Nokia-style Snake game built with Python's built-in Turtle graphics module.

   ## How to run
   python snake.py
   (No install needed. Turtle comes with Python.)

   ## Controls
   Arrow keys to move. Eat food to grow; don't hit the walls or yourself.
